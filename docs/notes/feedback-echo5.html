echo5 - an additive 3D cage that smears itself into glow trails

The "echo" of echo5 is not a feedback of the picture into itself by warping: it is a tiny software 3D engine drawing into the 8 bit buffer TEMP8. A cage of 33 square sheets (11 along each axis, at -100..+100 in steps of 20; 132 vertices, 66 triangles) is rotated by an angle that integrates the change of the script expression (0.5*Frame only matters through its per-frame difference), pulsed by three sine waves and pushed 1200 units away. Every triangle is drawn additively (dest += texel, wrapping) with a perspective-correct texture mapper; the texture is 2500 random soft blobs generated at start from the C rand(). The buffer is never cleared: after drawing, each pixel gets 0.65 x the already smeared pixel on its left, then 0.65 x the one above - the glow trails and the overexposed look. The result is turned into colours later by palette + doubleimage.

Because adding commutes, the polygon order does not matter (the original still files polygons into 4096 depth buckets by 0.2 x (z0+z1+z2), farthest first, and drops those beyond bucket 4095). The same triangle library was found in the sister demo (echo4 / echo6); here the projection scales are -0.625 / -0.390625 (pushed by the init, 0x1534c0).

original
init 0x11807c, run 0x1180dc, kernel 0x155628, mesh 0x154ee8, bins 0x1535a8, polygon loop 0x153a8c, triangles 0x18337a (4 clip stages, rasteriser 0x18253d)
quirk
the texture generator consumes the global rand() sequence, so it depends on what ran before it (cellrd's preinit): the port shares ctx.randSeed
verified
300 consecutive frames byte-identical to the original (feedback included); the triangle pipeline separately on 900 random triangles (incl. clipping); per-frame x87 products of the angle and phases are emulated in extended precision (x87.js)
