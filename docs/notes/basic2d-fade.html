fade — cross-fade to a colour with two 64 KB lookup tables

fade {IN} {OUT} {r g b expression} blends the image towards the colour (r,g,b) (floats 0..1) by an amount that is the expression evaluated at the event-local Frame: f = (int)(expr*255), truncating (the helper 0x103d1a forces the FPU control word to round-toward-zero). With f <= 0 the effect is a plain copy of the input; the script uses black and 1 - sin&sup4;(0.0071·Frame), so the Fears picture flashes in and out. The parameter text is read by sscanf("%f %f %f %s"): the expression must contain no spaces.

No multiplication is done per pixel. At start-up the engine builds two 256x256 byte tables, A[f][v] = ((256-f)*v) >> 8 (the image) and B[f][v] = (f*v) >> 8 (the colour). For every frame the code patches the table address into three instructions of the pixel loop (self-modifying code, 0x14bc8f) and puts the already scaled colour into an add eax,imm32 at 0x14bd11. The loop then costs three byte loads, three table lookups and one add per pixel; the result has alpha 0.

; fade run, 32 bit (0x1111b8): f -> [esp+0xc], colour channels scaled to 0..255 and truncated
1111b8  fld qword [0x1ad1a3]       ; 255.0
1111be  fld dword [esi+4]          ; g
1111c1  fmul st(1)
...
1111d2  call 0x103d1a              ; truncate (frndint with RC=3)
1111fb  shl eax, 8                 ; g
1111fe  shl edx, 0x10              ; r
111205  or eax, edx
11120d  or ecx, eax                ; ecx = 0x00RRGGBB colour*255
111214  call 0x14bc88              ; patch the loop + precompute B[f][r,g,b]
11122c  call 0x14bcd0              ; run the loop over w*h pixels

; the loop 0x14bcd0 (self-modified): the [edx+0x270f] displacements are rewritten to A + f*256 by 0x14bc8f/95/9b
14bcf0  mov al, [edx+0x270f]       ; A[f][r]
14bcf6  mov bl, [ebp+esi+1]        ; g
14bcfa  shl eax, 0x10
14bcfd  mov cl, [ebp+esi]          ; b
14bd01  mov ah, [ebx+0x270f]       ; A[f][g]
14bd07  add esi, 4
14bd0a  mov al, [ecx+0x270f]       ; A[f][b]
14bd11  add eax, 0x121212          ; imm patched = B[f][colour]  (placeholder 0x121212)
14bd16  mov dl, [ebp+esi+2]        ; next r
14bd1a  mov [edi+esi-4], eax

const k = 256 - f;  for (v = 0; v < 256; v++) t[v] = (k * v) >> 8;           // A[f][.]
const col = (((f*R) >> 8) << 16 | ((f*G) >> 8) << 8 | (f*B) >> 8) >>> 0;  // B[f][colour], R=(int)(r*255) ...
d[i] = ((t[p >> 16 & 255] << 16) | (t[p >> 8 & 255] << 8) | t[p & 255]) + col;
