plasma1volume — a 3D sine plasma with eight-fold symmetry

plasma1volume VOLUME a b fills the field with a + b·sin(r + 0.02·Frame), where r is the distance of the voxel from the centre of the cube. The distance table (16×16×16 floats, sqrt((x−7.5)²+(y−7.5)²+(z−7.5)²)) is built once by the init function at 0x2001f0. The run kernel exploits the symmetry: it evaluates only one octant (8×8×8 = 512 fsin) and stores every result four times (x, y mirrored), then copies the 8 finished planes onto their mirror planes with rep movsd. In the script it is multiplied (mulvolume) into the metaball/morph field to give the surface a changing organic texture.

; kernel 0x1522af, st1=a st2=b st3=phase;  edi=distance table, eax=volume plane
1522d6  fld dword [edi]            ; r
1522d8  fadd st(3)                 ; + phase
1522da  fsin
1522dc  fmul st(2)                 ; * b
1522de  fadd st(1)                 ; + a
1522e0  fst dword [eax+edx]        ; (x,y)
1522e3  fst dword [eax+esi]        ; (15-x,y)
1522e6  fst dword [eax+ebx]        ; (x,15-y)
1522e9  fstp dword [eax+ebp]       ; (15-x,15-y)
...                                ; edx+=4, esi-=4, ebx+=4, ebp-=4, edi+=4
152334  rep movsd                  ; plane z -> plane 15-z (256 dwords)

const v = f32(a + b * Math.sin(PLASMA_TAB[x + 16*y + 256*z] + phase));
vol[o + x + 16*y] = v; vol[o + (15-x) + 16*y] = v; vol[o + x + 16*(15-y)] = v; vol[o + (15-x) + 16*(15-y)] = v;
/* then for z < 8: vol.copyWithin(256*(15-z), 256*z, 256*z + 256) */
