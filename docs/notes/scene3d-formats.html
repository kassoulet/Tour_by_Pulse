The 3D scene system: files, loaders and conventions

The scene effect of TOUR is the demo's whole 3D engine (source name Bscene1.c, with loaduexp.c, loadlws.c, matmgr.c, hsort.c). A script line such as addEvent scene ipl {SCREEN} {SCREEN} {tentacle.exp 50.0 80.0} {0 0} parses "%s %f %f %c" (file, speed, offset, flag), loads the scene and does nothing else until play ipl installs the render callback 0x105e0c in the scene record. From then on the effect draws on top of whatever the earlier events left in the buffer: the scene time is (Frame - playStart) * speed * 0.01 + offset scene frames and the animation restarts when it passes duration - 0.5.

Two file families exist, both small binaries made by the group's own converters (same lineage as 73 Million Seconds, but the build differs: TOUR renders into 32 bit 640x480 and the .exp loader keeps five texture slots per material). .exp (UEXP) is an export of a 3D Studio MAX scene: world-space vertices, per-corner uv, a node matrix, position tracks, a target camera with fov track and omni lights; the loader derives object-space vertices as (p - T) * M^-1. .lwe (UNLW) is a LightWave scene reduced to motion keys (44 byte Kochanek-Bartels keys) referring to a .lwv object; the loader flips the z axis, so the object matrix is S R(h,p,-b) S. A chunk of type 0x0b attaches an object modifier (see the effects note).

; 0x11c24a  chunk dispatch of the .lwe loader: ah = chunk id, jump table in the code segment at 0x11c070
11c22a  mov  ah, byte ptr [ebp - 1]
11c22d  cmp  ah, 0xff                       ; end of file
11c236  mov  al, ah
11c238  dec  al
11c23a  cmp  al, 0xa
11c23c  ja   0x11cb89                       ; unknown id: skip
11c246  jmp  dword ptr cs:[edx*4 + 0x11c070]   ; 1 object, 2 camera, 3 light, 4 null, 0xb modifier
; material: the draw routine is chosen from the mode byte [mat+0xa6] (0x11f181), e.g. mode 4 with slot 4 -> 0x84
11f181  mov  dl, byte ptr [eax + 0xa6]
11f187  cmp  dl, 0x23
...
11f2be  mov  dword ptr [eax + 0x50], 0x124624   ; mode 0x84 : 32 bit polygon routine
