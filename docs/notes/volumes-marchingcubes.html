marchingcubes — polygonising a 16×16×16 field every frame

marchingcubes test box01 OurVolume 1 turns the field into triangles at the fixed iso-level 0.65 and pours them straight into the mesh of the object box01 of the scene test (box3.exp): the object's vertex array is replaced by 3×4096 preallocated vertex slots (0x60 bytes each, 0x120000 bytes), its face array by up to 4000 face records (0x3c bytes, copy of the first face so the material is kept) and the object's face count is set every frame. The volume cube is stretched over the bounding box of the object (1/15 of its size per cell). The last parameter selects Gouraud (2) or flat (1) shading in the object header.

The routine at 0x151ab8 is hand-written x87 assembly. It scans the 4096 samples once; for each sample it looks at the three edges that arrive from the lower neighbours. An edge carries a vertex when exactly one end is above the threshold (the float bit patterns are compared as signed integers). The vertex is placed by linear interpolation, and its normal is the interpolated central-difference gradient of the field, normalised with a table-driven 1/sqrt: the exponent is halved with integer arithmetic, the 8-bit mantissa comes from a 128-byte table, and one Newton step r·0.5·(3−r²·|g|²) finishes. Vertex slots are indexed by edge, so triangles share vertices and only the coordinate along the edge and the normal are rewritten per frame. Triangles come from the classic 256-case table (64 bytes per case at 0x1b340c), the case index being the 4 inside-bits of the current z-plane square joined to the 4 bits of the plane below (kept in a scratch array whose address is patched into the code, self-modifying style). The face normal is the cross product of two edges.

Edge test and interpolation (x edge, 0x151af4)

151af4  mov eax, dword [esi+0x440]   ; v0 = volume[x-1]
151afa  mov ebx, dword [esi+0x444]   ; v1 = volume[x]
151b00  cmp eax, ecx                 ; ecx = bits of the threshold 0.65f
151b02  jl  0x151b0e
151b04  cmp ebx, ecx
151b06  jge 0x151c2f                 ; both above: no vertex
151b0c  jmp 0x151b16
151b0e  cmp ebx, ecx
151b10  jl  0x151c2f                 ; both below
151b16  fld dword [esi+0x444]        ; t = (v1 - thr) / (v1 - v0)
151b1c  fsub dword [0x1f6330]
151b22  fld dword [esi+0x444]
151b28  fsub dword [esi+0x440]
151b2e  fdivp st(1)

Fast normalisation (0x151b83)

151b83  fstp dword [0x1bdc48]        ; |g|^2 as float
151b89  mov eax, dword [0x1bdc48]
151b8e  mov ebp, 0xbe000000
151b93  shr eax, 0x11
151b96  mov edx, dword [0x1bdc48]
151b9c  and eax, 0x7f                ; top 7 mantissa bits
151b9f  and edx, 0x7f800000          ; exponent
151ba7  sub ebp, edx
151ba9  shr ebp, 1                   ; exponent of 1/sqrt
151bab  mov bl, byte [eax+0x1b7414]  ; mantissa from the 128 byte table
151bb1  shl ebx, 0xf
151bb7  and ebp, 0x7f800000
151bbe  or  ebp, ebx
151bc0  mov dword [0x1bdc50], ebp    ; r ~ 1/sqrt(|g|^2), then k = r*0.5*(3 - r*r*|g|^2)
