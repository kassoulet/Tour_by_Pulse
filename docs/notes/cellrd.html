cellrd - a Gray-Scott reaction-diffusion automaton driven by lookup tables

The pink worms that crawl through the lower left and upper right of the glass-scene section are a chemical simulation: two species A and B (5 bit each, 0..31) live on a 260 x 140 torus, A is spread by a 5x5 box blur, B by a 3x3 blur, and the Gray-Scott reaction dA = F(1-A) - A B², dB = A B² - (F+k) B turns them into spots, stripes and worms. The script gives 0.012 0.045 3.2 = feed F, kill k and a time step.

The clever part is that no floating point happens per cell. At preinit time the demo precomputes two tables of 16 bit results, indexed by (neighbourhood sum << 10) | (B << 5) | A: 776 x 1024 entries for A (the 5x5 sum is at most 25 x 31) and 280 x 1024 for B (3x3 sum), 1.6 MB + 0.57 MB, filled by a float loop (0x14ed9c). Every frame the cell step is two box sums, one packed index and one table read; the low byte of the 16 bit table value is the fraction, and a pseudo random dither byte is added before the result is truncated to 5 bit (stochastic rounding, so slow reactions still progress). The original runs two steps per frame, draws eight moving 3x3 "blob" seeds (sines) into the field first, and then paints the 260 x 140 field twice into the 32 bit screen (at 0,195 and at 378,156) through a 1024 entry colour table.

Table builder (0x14ed9c, table 2 shown)

14ef82  fild dword ptr [esp+0x28]      ; S = 3x3 sum of B (0..279)
14ef86  fld  dword ptr [0x2142cc]      ; F = 0.012
14ef8c  fadd dword ptr [0x2142c8]      ; F + k
14ef94  fmul dword ptr [0x1b0438]      ; S * (1/31)  -> mean in 0..1 units
14ef9c  fmul dword ptr [esp+0x3c]      ; (F+k) * w        (w = 0.7 * B/31, float32)
14efa4  fsubr dword ptr [esp+0x20]     ; A w^2 - (F+k) w   (A w^2 precomputed per A,B)
14efaa  fmul qword ptr [0x1b043c]      ; 0.7 * s
14efb2  fmul dword ptr [0x2142c4]      ; * D (3.2)
14efbe  fmul qword ptr [0x1b0458]      ; 0.7 s / 9 = mean of the 3x3 w
14efc4  faddp st(1)                    ; D*(reaction) + mean
14efc6  fmul qword ptr [0x1b0460]      ; / 0.7  back to B units
14efcc  fmul dword ptr [0x1b0454]      ; * 31
14efd2  fstp dword ptr [esp+0x34]      ; float32, clamped to [0,31], then floor(v*256) is stored as a word

The cell kernel (object 2, 0x2073e - self-modifying: the three table addresses are patched in by 0x20400)

2075e  mov eax, dword ptr [edx]              ; packed index of A: (sumA5 << 10) | (B << 5) | A
20760  add bl, byte ptr [ebp+NOISE]             ; running dither byte (patched: noise table 0x214288)
20766  mov ax, word ptr [eax+eax+TABLE_A]       ; 16 bit new value of A (patched: 0x214280)
2076e  mov ecx, dword ptr [edx+0x410]           ; packed index of B: (sumB3 << 10) | (B << 5) | A
20774  mov cx, word ptr [ecx+ecx+TABLE_B]      ; (patched: 0x214284)
2077c  add ebp, dword ptr [esp]                 ; noise index += loop counter (a bug: the random step pushed by the caller is never used)
2077f  add eax, ebx                             ; + dither
20781  and ebp, 0x7fff
20787  mov byte ptr [esi], ah                   ; new A = high byte
20789  add ecx, ebx
2078b  mov byte ptr [edi], ch                   ; new B

Port

const ab = (B[i] << 5) | A[i];
bl = (bl + noise[ep]) & 255;  ep = (ep + (65 - ((x - 2) >> 2))) & 0x7fff;   // the original adds its loop counter (65..1 per group of 4 pixels)
A2[i] = (t1[(s5[i] << 10) | ab] + bl) >> 8;
B2[i] = (t2[(s3[i] << 10) | ab] + bl) >> 8;
script
addEvent cellrd sellu {} {} {preinit grayscott 0.012 0.045 3.2 none} (tables, at script start, then deleted); addEvent cellrd sellu2 {} {SCREEN} {run} (orders 18-22). The 5th word names an initial-pattern file; none skips it.
state
all global (0x2142a4-0x2142dc): arrays 264 x 144 bytes (2 cell border, periodic), box-sum arrays, 8 blob records, rand() state (srand(12345) at preinit; the noise table is 32768 rand() bytes; the step draws 4 more per step)
colours
R = 255(1.5-2a), G = 255(b + 4.3 a b² - 0.2), B = 255(1 - 0.6 sin 5b - 1.2 a), a = A/31, b = B/31, 0x00RRGGBB
verified
both 16 bit tables, the palette, the noise table, A, B and the 640x480x32 screen bit-identical to the original for 400 frames (800 steps); the 80 bit x87 arithmetic of the table builder is emulated with BigInt where float32 results sit on a rounding tie
speed
about 2.5 ms per frame (two steps + draw) in node
