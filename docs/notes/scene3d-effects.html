Mesh effects: displace247, displacenorm, bomb and the LightWave displacement modifier

Three effects reach into a running scene by event name and rewrite the vertices of one named object each frame. displace247 (script: {wscene1 Box02 0.3 -0.04 0.17+0.04*sin(Frame*0.002)}) wobbles every vertex radially around the object's centroid, v' = c + (v-c) * (1 + A*sin(|v-c|*F + Frame*S)), with three script expressions A, S, F evaluated per frame; displacenorm uses the same wave along the vertex normal. bomb ({ipl tentacle sqr(Frame*0.03)}) first unshares the mesh (three private vertices per triangle), then flies every triangle away from the object centre: centre' = g + dir * |c-g| * (1 + speed * d), with a per-face random speed (1.2 - |c-g|/max) * (rand()/32768 * 1.0 + 0.3). The C rand() is the Watcom linear congruential generator and its seed already holds 0x565bb039 when the script starts, so the explosion is the same every run (and is reproduced here).

The soap bubble of the first scene is different: its deformation is an object modifier stored in the .lwe (chunk 0x0b). Each frame every vertex is projected spherically around the position of a Null object, looked up in the 256x256 height map Disp2.tga (tiled 3 x 4) and pushed outwards by up to 2 units, so the bubble wobbles as the Null flies away; the normals are rebuilt afterwards.
